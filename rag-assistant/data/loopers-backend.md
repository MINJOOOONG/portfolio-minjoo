# Loopers Backend (이커머스 백엔드) 프로젝트

## 개요

이커머스 백엔드 부트캠프에서 진행한 Spring Boot 기반의 백엔드 프로젝트입니다. QA Engineer로 근무하며 더 깊은 문제 이해를 위해 개발 역량이 필요하다고 느껴 자비를 들여 주말마다 수강한 부트캠프에서 진행했습니다.

## 기술 스택

- Java / Spring Boot
- Kafka (메시지 큐)
- 이커머스 도메인

## Kafka 활용

Kafka를 활용하여 이커머스 시스템의 비동기 메시지 처리를 구현했습니다. 주문 처리, 재고 관리 등의 이벤트를 Kafka를 통해 비동기적으로 처리하는 구조를 학습하고 적용했습니다.

## 이 프로젝트의 의미

- QA 업무 중 더 깊은 문제 이해를 위해 스스로 비용을 들여 학습한 프로젝트
- "본질 이해(Essence First)" 가치관을 실천한 사례
- 개발자, 기획자, QA 등 여러 직군의 관점을 함께 고려하며 문제를 바라보는 능력을 키운 경험
- Spring Boot와 Kafka를 활용한 백엔드 시스템 구축 역량 확보

## 이 프로젝트에서 보여주는 역량

- 자기주도적 학습 태도
- Spring Boot 기반 백엔드 개발 능력
- Kafka를 활용한 비동기 메시지 처리 이해
- QA와 개발 양쪽 관점을 모두 이해하는 크로스펑셔널 역량
