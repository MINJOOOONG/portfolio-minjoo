# QA Minjoo Helper 프로젝트

## 개요

토스(비바리퍼블리카)에서 QA Engineer로 근무하며 TC(Test Case) 관리 업무의 불편함을 해결하기 위해 직접 만든 보조 도구입니다.

## 배경 및 문제

- 토스에서는 TestRail 기반의 자체 테스트 관리 도구인 Tossion을 사용
- TC를 수정, 삭제, 추가하려면 매번 매니저에게 요청해야 하는 불편함이 있었음
- 반복적인 요청 과정이 업무 효율을 저하시키고 있었음

## 해결 방법

- Claude와 Codex를 적극 활용하여 개발
- 기존 TC API 구조를 참고해 Tossion과 유사한 자체 페이지를 구현
- 업무 시작 버튼을 누른 뒤 수정하거나 추가하고 싶은 TC를 기록
- 업무 종료 버튼을 누르면 변경 내역이 한 번에 가독성 있게 정리되도록 구현

## 성과

- 반복적인 요청 과정을 줄여 업무 효율 향상
- 업무 내용을 더 명확하게 공유할 수 있는 흐름 구축
- AI 도구를 실무에서 문제 해결에 활용한 사례

## 사용 기술

- AI 도구: Claude, Codex
- API: Tossion TC API 참조

## 이 프로젝트에서 보여주는 역량

- 실무에서 불편한 점을 발견하고 직접 해결하는 개선 지향적 태도
- AI 도구를 활용한 빠른 프로토타이핑 능력
- QA 업무 프로세스에 대한 깊은 이해
